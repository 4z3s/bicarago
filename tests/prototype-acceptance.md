# Prototype Acceptance Checklist

## Home
- [ ] Swap Indonesia ⇄ English bekerja.
- [ ] Exact seed phrase menghasilkan translation yang benar.
- [ ] English result menampilkan easy pronunciation.
- [ ] Unknown phrase tidak menghasilkan translation palsu.
- [ ] Copy bekerja pada secure/local context.
- [ ] Favorite tersimpan di perangkat.

## Speech
- [ ] TTS English dapat diputar pada browser yang mendukung.
- [ ] Microphone meminta permission hanya setelah user action.
- [ ] Unsupported speech API menghasilkan pesan yang jelas.

## Navigation/UI
- [ ] Home, Percakapan, Belajar, Favorit, Saya dapat dibuka.
- [ ] Mobile 360px tidak horizontal overflow.
- [ ] Desktop tetap terbaca.
- [ ] Light/dark dapat dipakai.
- [ ] Keyboard focus dapat digunakan.

## PWA
- [ ] Manifest dapat dimuat.
- [ ] Service worker diuji melalui HTTP localhost/HTTPS.
- [ ] App shell tetap tersedia setelah cache terbentuk.

Record actual PASS/FAIL only after execution.
