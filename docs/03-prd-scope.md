# PRD / Scope V1

## Product
BicaraGo — komunikasi praktis Indonesia ⇄ English.

## Primary Jobs
- “Saya ingin mengatakan sesuatu dalam English sekarang.”
- “Saya ingin tahu cara membacanya.”
- “Saya ingin mendengar pronunciation.”
- “Saya ingin menyimpan kalimat yang sering dipakai.”
- “Saya ingin belajar dari frasa percakapan nyata.”

## Core Screens
Home/Translate, Conversation, Quick Phrases, Learn, Favorites, History, Login/Register, Profile, Admin Content.

## Acceptance
Hasil terjemahan harus memisahkan source text, target text, dan easy pronunciation. Pronunciation hanya ditampilkan untuk teks English. Konten published harus melewati workflow review.
