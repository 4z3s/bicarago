# UI/UX Specification

## Main interaction
Header → language selector/swap → large input → translate → result card → English → easy pronunciation → meaning → Listen/Copy/Favorite → quick phrases.

## Mobile navigation
Home | Percakapan | Belajar | Favorit | Saya

## Design
Use `public/assets/4z3s/css/style4z3s-moderen.css` as primary design system during CI4 migration; Bootstrap only grid/utilities.

## Accessibility
Touch targets ≥44px, visible focus, semantic labels, keyboard support, contrast, reduced motion support, screen-reader labels.

## Canonical rule
Once prototype is approved/frozen, CI4 migration must preserve layout, navigation, section order, component position, and responsive behavior.
