# Business Process

## Quick Translate
Input teks/suara → validasi → tentukan arah id/en → cari verified phrase/cache → provider translation bila perlu → hasil English/Indonesia → easy pronunciation untuk English → TTS → optional save/history.

## Quick Phrase
Pilih kategori → cari frasa → buka detail → dengarkan → salin/tampilkan → favorit.

## Learning
Pilih kategori/lesson → lihat arti → lihat cara baca → dengarkan → latihan → quiz → simpan progres.

## Content
Editor membuat draft → Translator/Reviewer memeriksa → verified → published → archived bila tidak berlaku.

## Failure
Jika provider eksternal gagal, sistem tidak memalsukan hasil. Gunakan konten lokal terverifikasi bila tersedia dan tampilkan status layanan secara aman.
