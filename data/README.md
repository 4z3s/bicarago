# BicaraGo Data

PRE-CI4 content sources.

- `languages.json` — active V1 languages.
- `categories.json` — conversation/use-case categories.
- `phrases.json` — phrase seeds.
- `conversations.json` — scenario/dialog seeds.
- `vocabulary.json` — vocabulary + pronunciation + example seeds.

Prototype content is not automatically considered linguistically verified. Status must pass the content workflow before production publication.
